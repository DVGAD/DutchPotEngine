## Engine Goals

Name:
- DutchPot Engine
- DPE2D
Vision:  
- 2D side-scroller
- Editor-first workflow

**Summary**
DutchPot engine is designed as a 2D side-scrolling platformer engine with a focus on fluid, high-quality sprite animation and visual effects. 
The visual target is comparable to Streets of Rage 4 and Double Helix's Strider - smooth, layered, sprite-based rendering with dynamic visual feedback.
The primary goal of this project is to learn and master systems architecture and engine design in C++. 
DutchPot is being built editor-first, meaning the editor workflow is the core product, not any specific game. 
DutchPot exists to serve rapid prototyping and proof-of-concept development.
